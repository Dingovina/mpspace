# Прототип: сценарий селлера

Walkthrough кликабельного прототипа кабинета селлера (MPS-12, спринт 1).
Цель: убедиться, что основной сценарий собирается от входа до аналитики.

## Шаги прохода

1. Вход по email → личный кабинет селлера.
2. Раздел «Товары»: список товаров, фильтр по складу, карточка товара с остатками.
3. Раздел «Заказы»: лента заказов, статусы, детали заказа FBO/FBS.
4. Раздел «Аналитика»: продажи за 30 дней, топ товаров, динамика по дням.
5. Настройки: подключение API-ключа маркетплейса, проверка маски ввода.

## Результат

Сценарий собирается целиком, тупиковых экранов нет, переходы соответствуют
карте экранов из ЛР 1. Найденные мелкие замечания — в findings.md.
