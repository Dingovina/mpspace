# Прототип: сценарий бренда

Walkthrough кликабельного прототипа кабинета бренда (MPS-12, спринт 1).
Цель: убедиться, что сценарий контроля представительства собирается целиком.

## Шаги прохода

1. Вход по email → переключение на кабинет бренда.
2. Раздел «Товары бренда»: карточки, привязка к продавцам.
3. Раздел «РРЦ»: мониторинг розничных цен по SKU, пороги отклонений.
4. Уведомления: событие «РРЦ ниже порога», переход из письма в дашборд.
5. Выход и повторный вход: сохранение выбранного кабинета.

## Результат

Сценарий собирается: от привязки товаров до уведомления о нарушении РРЦ.
Замечания по прототипу — в findings.md.
